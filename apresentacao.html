  • pop(idx) → remover por índice
  • clear() → limpar tudo
  • [idx] → acessar por índice

📜 Histórico — Encadeamento de Métodos

Cada processamento aplicado é salvo automaticamente em uma segunda lista:

self.historico: list[tuple[str, np.ndarray]] = []

def _adicionar_ao_historico(self, descricao, mat):
    self.historico.append((descricao, mat.copy()))  # salva cópia da Mat

Fluxo de encadeamento:

  • Aplica Filtro Gaussiano → resultado vai pro histórico
  • Seleciona no histórico → clica ⬆ Usar como Base
  • A base agora é o resultado filtrado → aplica Binarização Otsu em cima
  • Pipeline encadeado sem perder os passos intermediários!

🎨 ★Cinza-Manual — Conversão de Cor

Fórmula ITU-R BT.601:

Y = 0.299×R + 0.587×G + 0.114×B
O verde tem peso maior (0.587) porque o olho humano é mais sensível a ele.

Código:

def _cinza_manual(self, img_bgr):
    b = img_bgr[:,:,0].astype(np.float64)
    g = img_bgr[:,:,1].astype(np.float64)
    r = img_bgr[:,:,2].astype(np.float64)

    cinza = (0.114*b + 0.587*g
           + 0.299*r).astype(np.uint8)
    return cinza

🔵 ★Média-Manual — Filtro Passa-Baixa

Princípio:

Cria um kernel k×k onde cada peso = 1/(k²) — é a média aritmética dos vizinhos.

Kernel 3×3: ┌──────────────────┐ │ 1/9 1/9 1/9 │ │ 1/9 1/9 1/9 │ │ 1/9 1/9 1/9 │ └──────────────────┘

Código:

def _media_manual(self, img, k):
    # Kernel com pesos iguais
    kernel = np.ones((k, k),
             dtype=np.float32) / (k * k)

    # Convolução 2D
    return cv2.filter2D(img, -1, kernel)
Quanto maior o kernel, mais borrada fica a imagem.

📐 ★Sobel-Manual — Detector de Bordas

Kernels definidos à mão:

Gx (bordas verticais): ┌──────────────┐ │ -1 0 1 │ │ -2 0 2 │ │ -1 0 1 │ └──────────────┘ Gy (bordas horizontais): ┌──────────────┐ │ -1 -2 -1 │ │ 0 0 0 │ │ 1 2 1 │ └──────────────┘

Magnitude:

M = √(Gx² + Gy²)
# Convolução com cada kernel
gx = cv2.filter2D(gray, cv2.CV_64F, kx)
gy = cv2.filter2D(gray, cv2.CV_64F, ky)

# Magnitude do gradiente
mag = cv2.magnitude(gx, gy)
return cv2.convertScaleAbs(mag)

⬛ ★Otsu-Manual — Binarização

Algoritmo:

  • Calcular o histograma (256 bins)
  • Para cada limiar t de 0 a 255:
  • Separar pixels em 2 classes
  • Calcular variância entre classes
  • O t que maximiza a variância é o ideal
Encontra o limiar automaticamente — sem necessidade de ajuste manual.

Código (simplificado):

for t in range(256):
    peso_bg += hist[t]
    peso_fg = total - peso_bg

    soma_bg += t * hist[t]
    media_bg = soma_bg / peso_bg
    media_fg = (soma_total-soma_bg) / peso_fg

    # Variância entre classes
    var = peso_bg * peso_fg
        * (media_bg - media_fg) ** 2

    if var > max_var:
        melhor_limiar = t

🔷 ★Erosão-Manual — Morfologia

Princípio:

Para cada pixel, olha a vizinhança k×k e pega o valor mínimo.

Vizinhança 3×3: ┌───────────────┐ │ 200 180 190 │ │ 210 220 205 │ │ 195 215 200 │ └───────────────┘ ↓ resultado = min(todos) = 180
Efeito: encolhe regiões brancas e remove ruídos pequenos.

Código:

def _erosao_manual(self, img, k):
    h, w = img.shape[:2]
    pad = k // 2

    # Padding com 255
    padded = cv2.copyMakeBorder(
        img, pad, pad, pad, pad,
        cv2.BORDER_CONSTANT, value=255)

    resultado = np.zeros_like(img)
    for i in range(h):
        for j in range(w):
            viz = padded[i:i+k, j:j+k]
            resultado[i,j] = viz.min()
    return resultado
